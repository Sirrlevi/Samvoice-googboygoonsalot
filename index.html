ABOUT

GoodBoyGoonsaLot

This interface is a modern creative layer around the existing JavaScript SAM implementation. The formant synthesizer itself has deliberately not been replaced by a neural TTS engine.

SAM was originally published in 1982 by Don't Ask Software for the Commodore C64 and is a reverse-engineered speech system. This project preserves the included engine and its documentation/attribution.

Important: Content Clone means speech-to-text → SAM speech. It does not clone a person's voice identity.
